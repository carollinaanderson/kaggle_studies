# Kaggle — Pandas Exercises

> Completed exercises from Kaggle's **Pandas** micro-course, applied to
> real datasets.

## Overview

Hands-on Pandas practice from the Kaggle Learn curriculum: reading and
writing data, indexing and selecting, summary functions, grouping and
sorting, data types, missing values, renaming, and combining datasets.

## Repository contents

| Notebook | Skill |
|---|---|
| `1. pandas-exercise-creating-reading-and-writing.ipynb` | Data I/O |
| `2. pandas-exercise-indexing-selecting-assigning.ipynb` | Indexing & selection |
| `3. pandas-exercise-summary-functions-and-maps.ipynb` | Summary functions |
| `4. pandas-exercise-grouping-and-sorting.ipynb` | Grouping & sorting |
| `5. pandas-exercise-data-types-and-missing-values.ipynb` | Data types & missing values |
| `6. pandas-exercise-renaming-and-combining.ipynb` | Renaming & combining |

## Tech stack

Python · Pandas · Jupyter Notebooks

## What this demonstrates

- Data wrangling fundamentals on real datasets
- Consistent, documented learning practice
