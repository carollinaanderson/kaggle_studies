# Kaggle — Intro to Machine Learning

> Completed exercises from Kaggle's **Intro to Machine Learning**
> micro-course.

## Overview

First-steps ML practice from the Kaggle Learn curriculum: exploring data,
building a first model, model validation, underfitting/overfitting, and
random forests.

## Repository contents

| Notebook | Skill |
|---|---|
| `01.exercise-explore-your-data.ipynb` | Data exploration |
| `02.exercise-your-first-machine-learning-model.ipynb` | First model (Decision Tree) |
| `03.exercise-model-validation.ipynb` | Model validation (MAE) |
| `04.exercise-underfitting-and-overfitting.ipynb` | Under/overfitting |
| `05.exercise-random-forests.ipynb` | Random forests |

## Tech stack

Python · Pandas · Scikit-Learn · Jupyter Notebooks

## What this demonstrates

- ML fundamentals applied end-to-end
- Model quality thinking (validation, bias-variance)
