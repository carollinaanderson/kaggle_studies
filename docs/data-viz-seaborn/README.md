# Kaggle — Data Visualization (Seaborn)

> Completed exercises from Kaggle's **Data Visualization** micro-course,
> using Seaborn.

## Overview

Hands-on visualization practice from the Kaggle Learn curriculum: hello
Seaborn, line charts, bar charts and heatmaps, scatter plots,
distributions, and a final project.

## Repository contents

| Notebook | Skill |
|---|---|
| `1.dataviz-exercise-hello-seaborn.ipynb` | Seaborn basics |
| `2.dataviz-exercise-line-charts.ipynb` | Line charts |
| `3.dataviz-exercise-bar-charts-and-heatmaps.ipynb` | Bars & heatmaps |
| `4.dataviz-exercise-scatter-plots.ipynb` | Scatter plots |
| `5.dataviz-exercise-distributions.ipynb` | Distributions |
| `6.dataviz-exercise-final-project.ipynb` | Final project |

## Tech stack

Python · Seaborn · Matplotlib · Jupyter Notebooks

## What this demonstrates

- Data storytelling through visualization
- Statistical chart selection
